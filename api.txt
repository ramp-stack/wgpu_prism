WGPU_PRISM API

wgpu_prism provides one public rendering entry point:

  Renderer<'surface>

    async fn new<W: wgpu::WindowHandle + 'surface>(window: W, width: u32, height: u32) -> Self
    fn resize(&mut self, width: u32, height: u32)
    fn update(&mut self, instructions: Vec<prism::drawable::Instruction>, scale: f32) -> bool
    fn render(&mut self) -> bool
    fn draw(&mut self, instructions: Vec<prism::drawable::Instruction>, scale: f32) -> bool

update retains one instruction list and returns whether the scene needs presentation. It compares
ordered instruction values exactly, using shared image identity rather than pixel comparisons.
Display scale changes and resize invalidate prepared geometry. Updates do not submit GPU work.

Call render in response to every OS redraw request, including requests for an unchanged scene.
It prepares geometry only when dirty, then draws and presents the retained scene. Initial empty
scenes are valid. draw is a convenience method that calls update and render unconditionally.
Both return true after presentation or false for a transient timeout. Surface loss triggers
reconfiguration and one retry; exhausted recovery and unrecoverable failures panic.

Window width and height are physical pixels. Instructions use logical coordinates.
Pass the window's display scale factor to update or draw. Do not pre-scale instructions.

Prism owns all drawing data:

  prism::drawable::Instruction
    offset: (f32, f32)
    bound: (f32, f32, f32, f32)  -- clip x, y, width, height
    item: Item

  prism::drawable::Item
    Shape(prism::drawable::shape::Shape)
    Text(prism::drawable::text::Text)
    Image(prism::drawable::shape::Shape, prism::hardware::Image, Option<Color>)
    Svg(prism::drawable::shape::Shape, prism::drawable::Svg, Option<Color>)
    The shape supplies display size and mask; its color is ignored for images.
    None preserves image colors. Some(color) replaces RGB and multiplies source alpha by color alpha.
    Images preserve aspect ratio and crop centrally to cover the shape.

  prism::drawable::Icon(pub prism::drawable::Svg, pub Color)
    Implements Drawable with the same scalable size request as Svg.
    Image, Svg, and Icon use their allocated layout size.
    Raster display resizing retains the original pixels and GPU texture identity.
    SVGs rasterize at the physical display size with a bounded shared cache.

  prism::drawable::shape::Shape
    stroke, width, height, angle, color, variant
    Variant: Ellipse, Rectangle, RoundedRectangle(radius)
    Angles are degrees. A zero stroke fills the shape.

  prism::drawable::text
    Font, Text, Span, Align, Character
    Prism performs text layout. The renderer rasterizes and caches its positioned glyphs.

  prism::drawable::Color
    RGBA bytes.

The renderer owns surface configuration, GPU pipelines, frame buffers, and image/glyph caches.
Ramp supplies a Maverick Renderer implementation around this type; no Maverick dependency
is required by wgpu_prism itself.

Data flow:
  Prism application -> Vec<Instruction> -> Ramp wrapper -> wgpu_prism::Renderer -> GPU

Dependency direction:
  Ramp -> Prism
  Ramp -> Maverick
  Ramp -> wgpu_prism -> Prism
